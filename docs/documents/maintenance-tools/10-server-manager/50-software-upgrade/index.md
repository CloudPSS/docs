**平台升级**页面支持查看 **CloudPSS** 包版本，以及对应用包进行安装、升级。

## 安装与升级

页面显示当前服务器的已安装的全部 **CloudPSS** 包软件，并支持上传更新包升级软件包版本。

页面结构如下：

+ **更新包名称**

+ **当前版本**： 如 1.0.0

+ **更新包版本**： 如 1.0.1

+ **包状态**：**可安装**、**可升级**、**已安装**三种包状态，默认显示**可安装**、**可升级**的软件包。
  
+ **操作：安装、升级**

![平台升级](./平台升级.png "平台升级")

### 添加包源

在**上传更新包**按钮右侧是包源列表，可以切换不同仓库的包源地址。允许用户自行添加/删除包源地址

![包源列表](package-list.png "包源列表")

![包源地址](package-url.png "包源地址")


### 安装更新包

在服务器拉取过源或者上传了安装包之后，如果当前设备未安装某软件包，操作列就会显示安装按钮，允许用户自行安装该软件包。

![安装更新包](./安装包.png "安装更新包")

### 升级更新包

在服务器拉取过源或者上传了安装包之后，如果当前设备已安装某软件包但是版本落后于新的软件包，操作列就会显示升级按钮，允许用户自行升级该软件包。

![升级更新包](./升级包.png "升级更新包")

## 上传更新

### 上传更新包

> 注意：此功能上传的更新包为 [CloudPSS 产品管理平台](https://admin.local.cloudpss.net/) 下载的 tar 压缩包文件。

以 **CloudPSS Caddy** 为例，解压后的文件包含以下内容：

+ **cloudpss-caddy_2.7.4_amd64.deb**：deb 安装包

+ **Import.sh**

+ **InRelease**

+ **Key**

+ **Packages**

+ **Release**

![tar 压缩包文件](./压缩包.png "tar 压缩包文件")

将该 tar 包上传，等待一段时间，页面会自动刷新更新包的版本号。

## 设置自动更新

点击**每日04:00自动更新**开关，开启/关闭自动更新

![自动更新](auto-update.png "自动更新")

## 升级历史

点击升级历史按钮，查看该服务器全部安装包升级历史信息记录，方便用户运维服务器安装包

![升级历史](update-history.png "升级历史")
