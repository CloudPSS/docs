本节主要介绍 IESLab 规划优化平台数据管理模块的**气象数据**、**设备信息**、**负荷信息**和**能源信息**等子模块。如需深入了解各模块功能文档，请跳转相应帮助文档查阅。

## 功能定义

数据管理模块是规划优化的**数据底座**。它负责录入并管理四类基础数据——**气象数据、设备型号库、负荷曲线、能源价格模型**（电/冷/热/氢/氨/燃料）。后续拓扑建模时，元件会绑定到这里的数据；启动计算时，平台把这些数据填入优化模型。

一句话概括其在五步流程中的位置：

```
① 数据准备（本模块） → ② 拓扑搭建 → ③ 方案配置 → ④ 启动计算 → ⑤ 结果查看
```

> **为什么第一步是数据**：优化结果的可靠性直接取决于输入数据质量。绝大多数"结果不合理"的排查，最后都能追溯到数据模块——单位填错、曲线缺失、价格模型未绑定。**建议在本模块就把数据核对清楚，不要带着疑问往下走。**

## 四个子模块

| 子模块                                       | 作用                                                         | 关键要点                                                                       |
| :------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------------------------- |
| [气象数据库](./10-meteorological-database/index.md) | 按项目所在地载入历史年逐时气象数据（辐照、风速、温度等）     | 决定光伏/风机的**理论出力**。平台内置 2016–2025 年数据，支持地图选点与二次编辑 |
| [设备数据库](./20-device-database/index.md)         | 管理各类设备的候选型号（额定功率、投资单价、效率、寿命、运维） | 构成选型优化的**候选型号池**；型号池越丰富，选型空间越大                       |
| [负荷数据库](./30-load-database/index.md)           | 录入电/冷/热/氢等负荷曲线                                    | 注意**单位为 kW（功率）**；曲线覆盖时段须与规划时段一致                        |
| [能源信息库](./40-energy-info-database/index.md)    | 建立电价、冷/热价、氢价、氨价与燃料价格模型                  | 决定购能成本与售能收益；**上网电价在此绑定**                               |

> **各子模块"第一件事"**：气象库先**选地点载入数据**；设备库先**建候选型号池**（每类 ≥ 1 个）；负荷库先**确认单位 kW 且曲线完整**；能源库**务必同时绑购电与上网电价**（见下节）。四个库都齐了，再进拓扑。

## 数据准备检查清单

启动计算前，请逐项核对：

| # | 检查项               | 常见问题                                                       |
| - | :------------------- | :------------------------------------------------------------- |
| 1 | 气象数据已载入       | 未载入 → 光伏/风机理论出力为 0，等同于"没装"                   |
| 2 | 负荷曲线完整无缺失   | 有空档会被自动插补，但建议保证主体完整；单位必须是 **kW**      |
| 3 | 电价模型已绑定       | 包括**购电电价**与**上网电价**（见下节）                 |
| 4 | 燃料价格已绑定       | 影响燃气锅炉、燃机等燃料设备的经济性                           |
| 5 | 设备候选库已建立     | 每类设备至少一个候选型号，否则该类设备无法参与选型             |
| 6 | 关键参数单位已复核   | 效率为 **0~1 小数**；比率类（上网率、自消纳率、SOC）为**百分数** |

## 最易遗漏 上网电价绑定

**这是导致"新能源富余电消纳不掉、模型无解或大量弃电"的头号原因，请务必确认。**

在[能源信息库](./40-energy-info-database/index.md)中建立电价模型时，需要同时提供**购电电价**与**上网电价**（售电电价）。若只绑定了购电电价而**未绑定上网电价**（或上网电价填 0），会产生连锁后果：

1. 上网收益为 0 → 模型认为"把电卖给电网毫无价值"；
2. 新能源大发时段的富余电因此只能选择**充入储能**或**弃掉**；
3. 储能充满后仍富余 → 触发**弃电惩罚**；极端情况（上网通道也被限制）下能量平衡无解；
4. 更隐蔽的是，当弃电惩罚高于储能充放电损耗时，模型会选择用储能**边充边放**来耗散富余电，触发"同时充放电"告警。

**正确做法**：

1. 在[能源信息库](./40-energy-info-database/index.md)的电价模型中，同时填写购电电价与**上网电价**（元/kWh）。分时电价需给出 24 小时曲线，上网电价可按当地脱硫煤标杆电价或双边协商电价填写；
2. 在拓扑中把外部电源的**上网电价**绑定到该价格模型；
3. 确认外部电源三项设置均已放开：`IsPowerToGrid` = 允许上网、`MaxiumPowerToGrid` > 0、`MaxFeedinRatio` > 0（**百分数**，20 表示 20%）。

> **孤岛系统的反向检查**：若您的项目**不允许上网**（如离网微网），则不必绑定上网电价，但要相应确认富余电有其他去处——足够的储能容量，或允许弃电。三个出口全被堵死会导致模型无可行解，详见[参数设置 · 上网电价绑定专题](../50-topology-module/20-topology-modeling-workflow/20-setting-params/index.md#5-上网电价绑定专题)。

## 数据导入导出

各子模块均支持**从文件导入 / 保存到文件 / 从典型库导入**：

- **保存到文件**：将当前数据另存为 Excel，可作为模板参考格式；
- **从文件导入**：选择对应类别的 Excel 文件，平台自动校验格式，格式有误会提示"表格格式不正确!"；
- **从典型库导入**：选择厂商与型号后自动填充参数，注意会**覆盖**当前参数，导入后需点击保存。

批量录入建议先导出模板、按格式填写后再导入，可显著减少逐项录入的工作量。
