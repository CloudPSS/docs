本节主要介绍 IESLab 规划优化平台进行方案优化时的**基本原理**、**方案配置**和**结果页面**。方案优化模块是平台规划优化业务的**计算与分析核心**：前两步（数据准备、拓扑搭建）为它准备输入，后三步（**方案配置 → 启动计算 → 结果查看**）都在本模块完成。下面三篇文档分别对应其中的配置、计算与结果环节。

## 三篇文档怎么选

| 如果你要…                                                 | 看这一篇                                |
| :--------------------------------------------------------- | :-------------------------------------- |
| 理解平台在算什么（目标、变量、约束、求解、聚类、财务原理） | [基本原理](./10-fundamentals/index.md)   |
| 知道每个参数怎么填、填错会怎样                             | [计算方案配置](./20-job-config/index.md) |
| 查看结果、读懂图表、排查异常                               | [结果页面](./30-results-tab/index.md)    |

> **建议阅读顺序**：先用[快速入门](../20-quick-start/index.md)跑通一个完整算例，再回到[基本原理](./10-fundamentals/index.md)理解模型在做什么；配置具体项目时查阅[计算方案配置](./20-job-config/index.md)；**结果出来后务必按[结果正确性判定](./10-fundamentals/index.md#9-结果正确性判定)做校验，再按[优化调试技巧](./30-results-tab/index.md#优化调试技巧)排查异常**。

## 最佳食用指南

项目搭建原则：

1. 先思考如何建模，如何抽象为一个优化模型，再用 IESLab 进行规划优化。正确定义问题，准确抽象一个数学优化模型，认真分析优化结果，平台只是一个求解工具，如果定义了一个错误的模型，再高级的求解器也无法真正解决问题。
2. 借助 AI，结合本文档，更深入理解平台和优化模型，可以帮助您快速熟悉平台。
3. AI 不能代替你的分析和决策，每次拿到结果，请先分析确认优化结果的合理性，无系统级缺电弃电和相应警告。更多判定方法与排障手册见[基本原理 · 结果正确性判定](./10-fundamentals/index.md#9-结果正确性判定)与[结果页面 · 优化调试技巧](./30-results-tab/index.md#优化调试技巧)。
