本节介绍了如何基于优化生成的方案结果进行更加细致的**财务评估**，同时查看财务分析得到的**经济性指标和报表**。阅读本文档，用户可以对利用本平台进行财务评估的步骤和过程有更加清晰的了解。

本文档假定读者不具备财务专业背景，在介绍平台操作的同时，系统性地讲解财务评估所依据的**基础财务理论**、**项目财务评价方法**、**各张财务报表的计算原理**以及**报表之间的勾稽关系**，帮助用户理解"每一个数字从哪里来、为什么是这样算出来的、它们之间如何互相印证"。

## 功能定义

通过设置项目生命周期、投资组成、资金来源等基础财务参数，利用优化得到的方案配置及运行数据，对项目进行全生命周期的财务评价，获得投资收益率、回报期等关键性财务指标，以及现金流量表等十余种财务报表。

财务评估的**输入**是方案优选模块输出的设备容量配置与8760小时运行结果（设备投资费用、各类能源的产出与消耗、年运行收支等）；**输出**是全生命周期（建设期+运营期）各年度的多张财务报表与汇总后的经济性指标。整个模型以"年"为计算粒度，将投资、融资、经营、纳税、还债、利润分配等全部换算为逐年数据，最终回答"这个项目值得投资吗"。

## 财务评估基础理论

本节介绍读懂报表和处理财务评估结果所必需的基础财务知识。如果已经熟悉项目财务评价，可以跳过本节直接阅读报表原理。

### 资金时间价值与折现

**资金时间价值**是指资金在不同时间点上具有不同价值：今天的一元钱比一年后的一元钱更值钱，因为可以投资生息。财务评估必须把不同年份的现金流量放在同一个时间基准上比较，这就是**折现（贴现）**。

折现的数学形式为：

```
某年现金流的现值 = 该年现金流 / (1 + 折现率)^年数
```

其中折现率即机会成本或基准收益率。基于折现可以定义两个最重要的指标：

- **财务净现值（NPV）**：把项目全周期的净现金流量按基准折现率折算到起点后的总和。NPV > 0 表示项目收益超过基准收益水平，可行；NPV < 0 表示项目达不到基准收益水平。
- **财务内部收益率（IRR）**：使项目净现金流量现值总和恰好等于 0 的那个折现率，即"项目自身的投资回报率"。IRR 越高，项目盈利能力越强。由于 IRR 的方程无法直接求解，本平台采用**牛顿迭代法**求解（从初始值 8% 出发迭代，相邻两次解的差小于千分之一时收敛）。

本平台概览指标中的**财务净现值**和**内部收益率**均按上述原理计算。

### 项目财务评价的两套口径

财务评估先把"项目整体"和"投资者角度"分开考察，对应两套现金流量表：

- **融资前分析（项目投资现金流量表）**：站在项目整体角度，不考虑钱是借来的还是自己的，现金流出只包括建设投资、流动资金、经营成本、税金，不含借款及其还本付息。它衡量**项目自身**的盈利能力，计算"项目投资内部收益率"。
- **融资后分析（项目资本金现金流量表）**：站在投资者的角度，只考察**自有资金（资本金）**的投入与回报，现金流出包含资本金投入、还本付息、所得税等。它衡量**投资者**的回报水平，计算"资本金内部收益率（即财务内部收益率，FIRR）"。

两者的关系是：融资前分析看"项目值不值得做"，融资后分析看"项目对股东划不划算"。

### 盈利能力评价指标族

本平台经济性指标分为**静态指标**（不考虑资金时间价值）与**动态指标**（考虑资金时间价值）两类：

| 类型 | 指标 | 含义 | 计算公式（本平台实现） |
| --- | --- | --- | --- |
| 动态 | 资本金内部收益率 | 资本金口径现金流 IRR | 使资本金净现金流量现值=0 的折现率（牛顿迭代） |
| 动态 | 项目投资内部收益率 | 项目整体口径现金流 IRR | 使总投资净现金流量现值=0 的折现率，分所得税前/后 |
| 动态 | 财务净现值 | 按基准折现率折算的净现值 | Σ 各年净现金流量×(1+基准折现率)^(-年数)，分所得税前/后 |
| 动态 | 投资回报期 | 收回全部投资所需年数 | 累计净现金流量首次转正的年份 + 插值修正 |
| 静态 | 总投资收益率（ROI） | 项目整体盈利能力 | 平均年息税前利润 / 项目动态总投资 × 100% |
| 静态 | 资本金利润率 | 资本金盈利能力 | 平均年净利润 / 项目资本金总额 × 100% |
| 静态 | 年销售收入 | 项目投产后年收入水平 | 运营期首年产品销售收入 |
| 静态 | 平均年总成本费用 | 运营期年均成本 | 运营期总成本费用之和 / 运营期年数 |
| 静态 | 项目动态总投资 | 含建设期利息的总投资 | 建设投资 + 建设期利息 + 流动资金 |

**投资回报期的插值计算**：观察累计净现金流量序列，找到首次由负转正的那一年 N，则回收期 = (N-1) + |第 N-1 年累计净现金流量| / 第 N 年净现金流量，即用线性插值精确到小数。

**为什么要同时看所得税前和所得税后**：所得税前指标反映项目"不含税负调节"的真实盈利能力，便于横向比较；所得税后指标反映投资者实际可获得的回报，更贴近现实判断。

### 全生命周期财务模型的总框架

财务评估把项目生命周期分为**建设期**与**运营期**。整个模型按以下顺序逐层推算：

```
① 投资估算（建设投资、流动资金）
   ↓
② 融资方案（资本金 + 债务资金、建设期利息资本化）
   ↓
③ 折旧与摊销 → ④ 总成本费用（含财务费用）
   ↓
⑤ 营业收入与税金 → ⑥ 利润与利润分配（所得税、公积金、股息）
   ↓
⑦ 现金流量表（融资前/融资后/财务计划）→ 概览经济性指标
   ↓
⑧ 资产负债表（资产 = 负债 + 所有者权益，校验全模型平衡）
```

每一层的输出都作为下一层的输入，层层递进、互相勾稽，最终由**资产负债表**验证整个模型年度平衡。

## 财务模型整体结构与勾稽关系

### 报表体系总览

平台共生成 11 张财务报表和 1 张概览表。其数据流动关系如下：

```
                            ┌─ 营业收入税金表(10) ─┐
 优化方案结果(systemData) ──┤─ 折旧摊销表(6) ──────┼──► 流动资金表(5)
 (收入/支出/投资)          │─ 投资使用计划表(4) ─┤       │
                            └─ 借款还本付息表(11) ─┘       │
                                 │                        │
     ┌──────────────────────────┼────────────────────────┘
     ▼                          ▼
  总成本费用表(7) ─────┐        │
     │                 │        │
     ▼                 ▼        ▼
  利润与利润分配表(1) ◄──────────┘ (总成本、税金输入)
     │
     ├───────────────► 项目总投资现金流量表(8)（融资前）
     ├───────────────► 项目资本金现金流量表(9)（融资后）
     ├───────────────► 财务计划现金流量表(3)
     └───────────────► 资产负债表(2)（平衡校验）
                              │
                              ▼
                          概览表(经济性指标)
```

**核心枢纽**：利润与利润分配表（表1）是连接"经营"与"现金流"的枢纽——它承接营业收入、总成本费用、税金，产出所得税与净利润；净利润又通过现金流量表影响累计盈余资金，通过公积金/未分配利润影响资产负债表的所有者权益。

### 核心勾稽关系

财务报表之间通过以下恒等式互相校验，任一环断裂都会导致后续数字错误。理解这些勾稽关系，是读懂报表、排查"对不上账"问题的关键。

**① 利润表勾稽链（表1）**

```
产品销售收入 − 销售税金及附加 − 总成本费用 = 利润总额
利润总额 − 弥补以前年度亏损 = 应纳税所得额（取非负）
应纳税所得额 × 企业所得税税率 = 所得税
利润总额 − 弥补亏损 − 所得税 = 净利润
净利润 − 法定公积金 − 任意公积金 − 投资方利润分配 = 未分配利润
```

**② 现金流勾稽链（表8/9/3）**

```
现金流入 − 现金流出 = 净现金流量
本年累计净现金流量 = 上年累计净现金流量 + 本年净现金流量
```

财务计划现金流量表的"累计盈余资金"即逐年累计的净现金流量，它同时作为资产负债表"流动资产"中的一项。

**③ 资产负债恒等式（表2）**

```
资产 = 负债 + 所有者权益
（流动资产 + 在建工程 + 固定资产净值 + 无形资产净值）
= （流动负债 + 建设投资借款）
+ （资本金累计 + 累计盈余公积 + 累计未分配利润）
```

平台在生成资产负债表时会逐年自动校验该等式，若不平衡会输出警告，提示检查上游报表。

**④ 成本勾稽（表6/7）**

```
经营成本 = 总成本费用 − 折旧费 − 摊销费 − 财务费用（利息支出）
```

折旧与摊销计入总成本费用，但**不产生现金流出**（钱在投资时已经花掉），因此在现金流量表中计算现金流出时用的是剔除折旧摊销后的"经营成本"。这是成本与现金流最容易被混淆的勾稽点。

**⑤ 投资勾稽（表4）**

```
项目总投资 = 建设投资 + 建设期利息 + 流动资金
资金筹措 = 项目资本金 + 债务资金（长期借款 + 流动资金借款）
项目总投资 = 资金筹措（两边必须相等）
```

**⑥ 所得税口径勾稽（表1/8）**

- 利润表中的"所得税"= 应纳税所得额 × 税率（按当年实际盈利计算）；
- 项目投资现金流量表中的"调整所得税"= 息税前利润 × 税率（融资前分析简化口径，只取非负）。
两者口径不同，不能互相替代，属正常差异。

| 参数名 | 含义 | 说明 |

| 还款方式 | 贷款偿还方式 | 默认值**等额本金**，可选**等额本金**或者**等额本息**。等额本金=每年还本金额相等（利息递减）；等额本息=每年还本付息总额相等（还本递增、付息递减）。还款计算详见**借款还本付息表（表11）**原理 |

| 材料费 | 在生产或建设过程中消耗的原材料和辅助材料的费用 | 默认值**5**，用户需填入**大于0**的数值。作为**可变成本**计入总成本费用，同时用于计算流动资金中的存货与应付账款 |
| 其它费用 | 包括运输费、差旅费等在内的非直接材料成本和非劳动成本 | 默认值**1**，用户需填入**大于0**的数值。作为**固定成本**计入总成本费用 |

> **增值税口径说明**：增值税是价外税，本平台采用的销项/进项税均为"价税分离"核算——含税收入中的税额部分单独分离为销项税额，购电、燃料、材料中的税额分离为进项税额，两者之差为应交增值税。增值税本身不计入成本费用，但会在现金流层面扣除（财务计划现金流量表），其附加税费（城建税、教育费附加、地方教育附加）则进入利润表的"销售税金及附加"。

## 财务报表计算原理

本节逐张说明每张报表的**编制目的**、**数据结构**和**核心计算方法**。报表在界面上以"项目-子项"树形结构展示，每个子项对应一列逐年数据，年份从项目建设期第一年至运营期最后一年。

### 1. 营业收入、税金、附加和增值税估算表（表10）

**编制目的**：估算项目投产后各类能源销售形成的收入，以及按增值税核算规则产生的各项税费，是利润表和现金流量表的税金数据来源。

**核心计算**：

```
营业收入 = 售电收入 + 售冷收入 + 售热收入 + 售氢收入
   （均来自优化运行结果中的年收入，建设期内为 0）

销项税额 = 售电收入×电税/(1+电税) + 售冷收入×冷税/(1+冷税)
         + 售热收入×热税/(1+热税) + 售氢收入×氢税/(1+氢税)

进项税额 = 购电支出×电税/(1+电税) + 燃料支出×燃料税/(1+燃料税)
         + 材料费×材料税/(1+材料税)

应交增值税 = 销项税额 − 进项税额
城建税 = 增值税 × 城建税税率
教育费附加 = 增值税 × 教育费附加税率
地方教育费附加 = 增值税 × 地方教育附加税率
营业税金及附加 = 城建税 + 教育费附加 + 地方教育费附加
```

**原理说明**：增值税 = 销项 − 进项，即只对"增值部分"征税。所有收入/支出先做"价税分离"（除以 1+税率），分离出税额再计税。城建税及附加以实缴增值税为计税基数。

### 2. 资产折旧与摊销估算表（表6）

**编制目的**：把项目的大额一次性投资在运营期内逐年分摊进成本（折旧/摊销），并计算资产的净值变化。

**核心计算**：

```
实际年利率 = (1 + 名义年利率/计息次数)^计息次数 − 1
动态投资 = 静态投资(含利息的逐年建设投资) + 建设期利息
年折旧费 = 动态投资总额 × (1 − 残值率) × 固定资产比例 / 折旧年限
年摊销费 = 动态投资总额 × (1 − 固定资产比例) / 摊销年限
固定资产原值 = 上一年净值 + 当年动态投资 × 固定资产比例（逐年累计）
固定资产净值 = 原值 − 累计折旧
无形资产原值/净值 同上，比例为 (1 − 固定资产比例)
```

折旧与摊销仅在**运营期**且处于折旧/摊销年限内的年份计提，超过年限后归零。**建设期利息**计入固定资产原值（即"利息资本化"），体现为动态投资高于静态投资的部分。

### 3. 流动资金估算表（表5）

**编制目的**：估算维持正常经营所需的周转资金。采用"周转次数法"，即资金占用额 = 年某项现金流出 / 该项年周转次数。

**核心计算**：

```
经营成本 = 材料费 + 工资及福利费 + 修理费 + 其它费用 + 保险费（+ 燃料等）
应收账款 = 经营成本 / 应收账款年周转次数
存货     = (材料费+燃料费)/存货周转次 + (经营成本−保险费)/存货周转次 + 经营成本/存货周转次
现金     = (工资福利 + 修理费 + 折旧费 + 摊销费) / 现金年周转次数
流动资产 = 应收账款 + 存货 + 现金
应付账款 = (材料费 + 燃料动力费) / 应付账款年周转次数
流动负债 = 应付账款
流动资金 = 流动资产 − 流动负债
流动资金本年增加额 = 本年流动资金 − 上年流动资金
```

**原理说明**：周转次数越大，说明资金周转越快、需要的占用资金越少。流动资金在建设期末一次性投入，在运营期末全额回收，是现金流量表"回收流动资金"的来源。

### 4. 投资使用计划与资金筹措表（表4）

**编制目的**：明确"钱花在哪里"（项目总投资）和"钱从哪里来"（资金筹措），是融资方案的总纲。

**核心计算**：

```
静态投资总额 = 设备购置费 + 建筑工程费 + 安装工程费 + 其他费用
各年建设投资 = 静态投资总额 × 投资批次比例（比例自动校正，合计=100%）

实际年利率 = (1 + 名义利率/计息次数)^计息次数 − 1
各年长期借款需求 = 各年建设投资 × (1 − 资本金比例) + 当年建设期利息
建设期利息：分年计算，当年发生的借款按半年计息（系数0.5），
          用不动点迭代法反复计算直至收敛（利息计入本金后本金变，再算利息）

项目总投资 = 建设投资 + 建设期利息 + 流动资金
项目资本金 = 用于建设投资的资本金 + 用于流动资金的资本金
债务资金   = 长期借款 + 流动资金借款
资金筹措   = 项目资本金 + 债务资金   （必须与项目总投资相等）
```

**建设期利息的迭代原理**：建设期利息不是一次性算出来的——当年借款额包含当年的利息，而利息又依赖于含息本金。平台通过不动点迭代（反复代入直到利息变化小于阈值）求解这一循环关系，保证建设期各年"借款+利息"与"资本金+"投入严格吻合。

### 5. 借款还本付息计划表（表11）

**编制目的**：按还款方式和宽限期安排，逐年计算各类借款的还本、付息金额与期末余额。

**核心计算**：

**长期借款**（三种还款方式）：

```
等额本金：宽限期后每年还本 = 当年贷款额 / 贷款年限，逐年累计；
          付息 = 期初余额 × 实际利率 + 当年新增贷款/2 × 实际利率
等额本息：年还款额 A = P·r·(1+r)^n / [(1+r)^n − 1]（P为贷款本金总额，n为贷款年限）
          宽限期内只付息；宽限期后每年还本 = A − 当年利息
           （利息逐年减少，还本逐年增加，总额恒定）
到期一次还本：贷款到期年一次性偿还全部本金，每年只付息
```

**流动资金借款**：运营期每年付息 = 期初余额 × 利率，运营期末一次性还清本金。

**短期借款**（动态平衡）：当某年净利润为负时，企业需要借入短期借款弥补资金缺口；净利润为正时优先用于偿还短期借款。因付息会影响净利润、净利润又影响借款需求，平台用不动点迭代（循环求解直到净利变化小于阈值）得到收敛解。

```
期初借款余额合计 = 长期借款余额 + 流动资金借款余额 + 短期借款余额
当期还本付息合计 = 长期借款还本付息 + 流动资金借款还本付息 + 短期借款还本付息
```

### 6. 总成本费用估算表（表7）

**编制目的**：汇集项目运营期的全部成本费用，区分固定/可变成本，并计算现金流量表所用的"经营成本"。

**核心计算**：

```
生产成本 = 燃料及动力费 + 材料费 + 工资及福利费 + 折旧费 + 摊销费
         + 修理费 + 其它费用 + 保险费
财务费用 = 长期借款利息 + 流动资金借款利息 + 短期借款利息
总成本费用 = 生产成本 + 财务费用
固定成本 = 工资及福利费 + 折旧费 + 摊销费 + 其它费用 + 保险费 + 财务费用
可变成本 = 总成本费用 − 固定成本
经营成本 = 生产成本 − 折旧费 − 摊销费     （现金流量表的现金流出项）
```

**原理说明**：折旧和摊销是"非付现成本"——它们计入成本、冲减利润，但不对应当年的现金支出（钱在建设期已经花了），所以现金流量表必须用剔除折旧摊销后的"经营成本"作为现金流出。财务费用（贷款利息）在建设期结束后才发生，是成本中与融资结构直接相关的部分。

### 7. 利润与利润分配表（表1）

**编制目的**：按年度核算项目盈亏和利润分配，是所得税、公积金、未分配利润等一系列后续计算的总开关。

**核心计算**：

```
利润总额 = 产品销售收入 − 销售税金及附加 − 总成本费用
弥补以前年度亏损：历年累计亏损先用盈利冲销（先弥补后计税）
应纳税所得额 = max(利润总额 − 当年弥补亏损, 0)
所得税 = 应纳税所得额 × 企业所得税税率
净利润 = 利润总额 − 弥补亏损 − 所得税
法定公积金 = max(净利润, 0) × 法定公积金率（10%）
任意公积金 = max(净利润, 0) × 任意公积金率
投资方利润分配 = max(净利润 − 法定公积金 − 任意公积金, 0)
未分配利润 = 利润总额 − 所得税 − 净利润
息税前利润(EBIT) = 净利润 + 财务费用（利息）
EBITDA = 息税前利润 + 折旧费 + 摊销费
```

**原理说明**：亏损弥补采用"先亏先补、补足为止"的规则；亏损年不缴所得税、净利润为负；盈利年先用利润冲销历年亏损，剩余部分才计税。EBIT 与 EBITDA 剔除了融资结构和折旧摊销的影响，用于衡量项目"纯经营"盈利水平，是总投资收益率和调整所得税的基数。

### 8. 项目总投资现金流量表（表8，融资前分析）

**编制目的**：站在项目整体角度，不考虑融资方式（借钱与否），考察项目自身盈利能力。用于计算"项目投资内部收益率"。

**核心计算**：

```
现金流入 = 产品销售收入 + 回收固定资产余值(末年) + 回收流动资金(末年)
  其中 回收固定资产余值 = 运营期末固定资产净值
       回收流动资金   = 运营期末流动资金余额
现金流出 = 建设投资 + 流动资金 + 经营成本
         + 城建税 + 教育费附加 + 地方教育费附加
所得税前净现金流量 = 现金流入 − 现金流出
调整所得税 = max(息税前利润, 0) × 企业所得税税率
所得税后净现金流量 = 所得税前净现金流量 − 调整所得税
累计净现金流量 = 逐年累加
```

**注意**：该表现金流出**不含借款本金与利息**（融资前口径），因此现金流量只与投资和经营有关；所得税按"调整所得税"（息税前利润 × 税率）简化估算，而非利润表中的实际所得税。

### 9. 项目资本金现金流量表（表9，融资后分析）

**编制目的**：站在投资者的角度，只核算自有资金（资本金）的实际投入与回报，考虑还本付息，用于计算"资本金内部收益率（财务内部收益率 FIRR）"。

**核心计算**：

```
现金流入 = 产品销售收入 + 回收固定资产余值 + 回收自有流动资金 + 短期借款新增
现金流出 = 建设投资资本金 + 自有流动资金 + 经营成本
         + 长期借款还本 + 流动资金借款还本 + 短期借款还本
         + 长期借款付息 + 流动资金借款付息 + 短期借款付息
         + 城建税 + 教育费附加 + 地方教育费附加 + 所得税
净现金流量 = 现金流入 − 现金流出
累计净现金流量 = 逐年累加
```

**与表8的区别**：表9 多出"资本金投入、借款还本付息、进口实际所得税"项，去掉"债务性投入（全部建设投资改为资本金口径）"，因此其净现金流量反映投资者的实际现金收支。

### 10. 财务计划现金流量表（表3）

**编制目的**：从企业经营、投资、筹资三类活动汇总现金收支，判断项目各年资金是否充裕（累计盈余资金是否为正）。

**核心计算**：

```
经营活动现金流入 = 销售收入 + 回收流动资金
经营活动现金流出 = 经营成本 + 城建税 + 教育费附加 + 地方教育费附加 + 所得税
经营活动净现金流量 = 流入 − 流出

投资、筹资活动现金流入 = 项目资本金投入 + 建设投资借款 + 流动资金借款
                       + 短期借款新增 + 回收固定资产余值
投资、筹资活动现金流出 = 建设投资 + 流动资金 + 借款本金偿还 + 借款付息
投资、筹资活动净现金流量 = 流入 − 流出

净现金流量 = 经营活动净现金流量 + 投资筹资活动净现金流量 − 应交增值税
累计盈余资金 = 逐年累加净现金流量
```

**注意**：净现金流量在两类活动之和的基础上再扣除应交增值税（增值税作为价外税单独在现金层面流出）。累计盈余资金进入资产负债表"流动资产"。

### 11. 资产负债表（表2）

**编制目的**：反映项目在任意时点的财务状况，并验证整个财务模型是否平衡。

**核心计算**：

```
流动资产 = 应收账款 + 存货 + 现金 + 累计盈余资金
在建工程 = 建设投资 + 建设期利息
资产总额 = 流动资产 + 在建工程 + 固定资产净值 + 无形资产净值

流动负债 = 应付账款 + 流动资金借款 + 短期借款余额
非流动负债 = 建设投资借款（长期借款余额）
负债总额 = 流动负债 + 非流动负债

资本金 = 各年项目资本金投入的累计
累计盈余公积 = 各年法定公积金 + 任意公积金 的累计
累计未分配利润 = Σ(净利润 − 公积金 − 应付股利) 的累计
              （末年再扣减"长期借款还本 − 固定资产残值"差额，
                体现处置固定资产偿还借款的会计处理）
所有者权益 = 资本金 + 累计盈余公积 + 累计未分配利润

校验恒等式：资产总额 = 负债总额 + 所有者权益（逐年验证）
```

**原理说明**："在建工程 → 固定资产"的转化、折旧导致净值下降、盈利形成未分配利润、借款偿还减少负债，全部通过资产负债表逐年滚动体现。平台在生成该表时会逐年自动校验**资产 = 负债 + 所有者权益**，若偏差超过容差会输出警告，提示排查上游报表——这是检验整套财务模型勾稽正确性的最后一道关卡。

## 常见问题

### 财务评价和方案优选的经济性目标测算有什么区别？

:   方案优选模块的经济性测算是相对比较粗略的，只考虑到了设备投资成本、设备年运维成本、购电以及购燃料等成本，并进行了简单的考虑项目生命周期的投资测算，而方案评估模块的财务评价则是从更加全面的评价维度对整个项目进行了财务分析。通常进行到方案评估模块的财务评价时，需要用户根据实际的设备建设规模对不同的优选方案设定不同的基础财务参数。

### 财务评估需要用户准备哪些输入？

:   两个层面：一是**方案结果**——由方案优选模块自动传入（设备投资费用、8760小时运行数据换算出的年收入/年支出/年运维费用），无需手动录入；二是**财务参数**——本文档"财务参数说明"中的六类参数，由用户按项目实际填写（建设期、资本金比例、利率、折旧摊销、成本费用、税率等）。建议先确认"建设投资明细"与"投资批次及比例"与项目实际资金安排一致。

### 为什么我改了资本金比例，报表里的净利润也变了？

:   这是正常的勾稽联动。资本金比例决定了借款规模，借款规模决定财务费用（利息），财务费用计入总成本费用，总成本费用直接影响利润总额与所得税。因此融资方案（表4）→ 借款还本付息（表11）→ 财务费用（表7）→ 利润（表1）是一条完整的传导链。这也是为什么"平均年总成本费用"这一概览指标会随融资结构变化的原因。

### 资产负债表提示"不平衡"警告是怎么回事？

:   平台在生成资产负债表时会逐年校验 `资产 = 负债 + 所有者权益`。若出现警告，通常意味着某一项来源数据异常，可以按以下顺序排查：① 确认"投资批次及比例"合计为 100%；② 检查折旧摊销表是否有年份超出折旧年限；③ 检查现金/流动资金估算是否出现负数；④ 检查累计未分配利润末年是否因还本调整出现负值。多数情况下是参数设置超出合理范围所致。

### 增值税为什么没有出现在利润表的成本里？

:   增值税是**价外税**，其税额已在销售/采购环节通过"价税分离"单独核算（表10的销项税额、进项税额），应纳税额只与"增值额"相关，不构成企业成本费用。因此利润表只包含以增值税为计算基数的城建税和教育费附加等"价内税费"，增值税本身在财务计划现金流量表层面从现金中扣除，避免重复计算。

### 内部收益率为 0 或显示异常，可能是什么原因？

:   内部收益率由牛顿迭代求解，当项目现金流符号多次反转（如后期又有大额资金投入）时，可能出现 IRR 不唯一或不收敛的情况，此时平台输出 0。建议先查看项目资本金现金流量表的"净现金流量"列，确认现金流是否呈现"先负后正"的常规形态；若运营期出现多年负现金流，需检查收入参数或建设投资分配是否存在问题。
