## 输出结果与报告

### 优化结果构成

一次成功的优化计算输出以下内容：

| 输出项 | 内容 | 查看位置 |
|:---|:---|:---|
| **设备选型配置** | 各设备选定的型号、台数与容量 | 方案列表 → 详细信息 |
| **运行策略** | 各典型日 24h 逐时出力/充放电/启停曲线 | 详细信息 → 查看曲线 |
| **全年 8760h 曲线** | 由典型日按权重重组的全年运行曲线 | 运行结果统计 |
| **能量平衡图** | 各载体供用能平衡（三种粒度） | 结果页默认展示 |
| **方案经济性指标** | 总投资、年运行成本、回收期等 | 方案列表 |
| **财务报表** | 11 张标准财务报表 | 财务后评估（需开启） |
| **Word 项目报告** | 图文并茂的可交付项目报告 | 一键生成（需开启） |

### 能量平衡图

优化完成后自动生成电/热/冷/氢等载体的**能量平衡图**，支持三种粒度：

| 粒度 | 说明 | 用途 |
|:---|:---|:---|
| 全年 8760h | 每小时供用能平衡 | 年度趋势分析 |
| 逐月汇总 | 每月供用能平衡 | 季节性分析、合规统计 |
| 典型日 24h | 每小时供用能平衡 | 日运行策略分析 |

图中**正值向上**为供应侧（发电/供热/产氢），**负值向下**为消耗侧（负荷/用热/用氢），可直观看出各时段供需缺口与设备利用情况。

![能量平衡图 =x700](./result.png "系统能量平衡图")

### 财务后评估报表

开启"优化结果后评估"后，平台自动计算并输出 **11 张标准财务报表**：

| 序号 | 报表 | 主要内容 |
|:---|:---|:---|
| 1 | 项目投资概算 | 总投资、分项投资、建设期利息 |
| 2 | 资金筹措计划 | 自有资金、贷款、还款计划 |
| 3 | 折旧与摊销 | 各设备折旧明细 |
| 4 | 成本费用估算 | 经营成本、固定/可变成本分解 |
| 5 | 利润测算 | 收入、成本、利润、税金 |
| 6 | 现金流量表 | 全生命周期现金流 |
| 7 | 敏感性分析 | 关键参数变动对 NPV/IRR 的影响 |
| 8 | 资产负债表 | 资产负债结构 |
| 9 | 财务指标汇总 | 投资收益率、回收期、NPV、IRR |
| 10 | 盈亏平衡分析 | 盈亏平衡点 |
| 11 | 临界分析 | 电价/投资等临界值 |

### Word 项目报告一键生成

开启"是否生成项目报告"后，优化结束自动生成结构完整、图文并茂、带数据分析的 Word 报告，覆盖：

- **项目源荷分析**：气象资源、负荷特性统计；
- **优化信息**：方案参数、约束配置、设备候选库；
- **结果展示**：设备配置表、运行曲线、典型工况与极端日筛选、能量平衡图（正值向上为供应侧、负值向下为消耗侧）；
- **综合评估**：经济性指标、合规统计（绿电直连项目含自发自用比例/上网比例/消纳比例的年度与月度统计）、结论建议。

分析文字全部由结果数据实时计算生成——过去一两天手工整理的报告，现在优化结束即自动生成。

> ![自动生成![alt text]项目报告=x700](./report.png "自动生成的项目优化报告")

## 优化调试技巧

当计算结果异常、求解停滞或无可行解时，可按以下思路在结果页与日志面板中定位问题（SimStudio 工作台的 **结果** 页对应 `result.png`、日志面板对应 `log.png`）。

### 1. 计算停滞 / 长时间无新方案

- 切换至 **显示日志** 面板（`log.png`）查看实时输出，确认是否卡在求解器阶段；
- 检查 `TIME_LIMIT`（默认 300s）与 `NUM_THREADS` 配置；大规模问题建议先做 **场景缩减**（聚类典型日）或采用 **两阶段并行优化**（先定容再并行运行）；
- 若长期无进展且占用内存高，通常是模型规模过大，优先降低聚类数目或收紧容量范围。

### 2. 提示无可行解（IIS / 约束冲突）

- 优先查看 **全局约束** 是否过紧：绿电直连的 `MinSelfUse` / `MaxFeedinRatio`、储能 `PowerGuarantee` 保供、弃电/上网比例等；
- 这些约束默认以 **软约束 + 松弛变量 + 惩罚项** 实现，会向目标函数追加 `PenaltySoft × Σ(slack)`。若松弛变量值偏大，说明约束实际未被满足——需要放宽参数或核查输入数据（理论出力、负荷曲线）；
- 设备容量上下限、爬坡率、始末容量一致等 **设备运行约束** 过严也会触发不可行，可先放宽容量范围试算。

### 3. 结果不符合预期

- 核对 **典型场景生成**：`月度平均` 计算快但精度低，`聚类` 兼顾效率与精度（默认 GMM 软聚类，类别数可由 BIC 自动确定），`8760h 全年` 精度最高但最慢；
- 检查典型日 **权重（kydt）** 是否正确映射全年；运行曲线与能量平衡图（`result.png`）应覆盖典型日与极端日；
- 经济性偏差常源于 **惩罚成本** 设置（电/热不平衡惩罚）与 **储能动作灵敏度**（避免无谓充放电里程）。

### 4. 求解器与列式

- 平台支持 HiGHS / SCIP / COPT / CBC ；含整数（选型、容量、启停 UC）时为 MILP，纯运行为 LP；
- 潮流默认 **交直流线性**（AC `ac_linear` + DC `dc`）。

> 调试优先级建议：**看日志 → 查松弛变量 → 放宽全局/设备约束 → 缩减场景/调求解器**。
