## 平台介绍

IESLab 规划优化平台是 CloudPSS 团队面向**电、冷、热、氢、气**等多能源耦合综合能源系统业务，自主研发的**规划优化工具**。平台以**交直流线性潮流内核**为基础，在您搭建的完整拓扑上自动建模功率平衡与潮流分布，把**设备选型定容（规划设计）**与**全年 8760 h 运行优化**放进同一套模型求解，并输出设备配置、运行策略、能量平衡图与财务报表，辅助投资决策。平台基于**云计算架构**，无需安装客户端、浏览器即可访问，支持公有云/私有云/本地部署与云边协同；并开放 **SDK 开发套件**支持高级扩展。

## 核心能力

| 能力维度                          | 支持内容                                                                                                                                                        |
| :-------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **拓扑化潮流建模**          | 交直流线性潮流：节点—支路—设备级功率平衡与潮流分布，自动识别基准电压与交直流母线；支持多节点、同一节点多台同型设备、每台设备多候选型号                        |
| **规划设计 + 运行优化一体** | 从候选型号池**选型定容**，再在典型场景或全年 8760 h 下**优化逐时运行**；提供统一模型与两阶段解耦两种求解架构，大规模问题可分区并行                  |
| **多能源载体与设备模型**    | 电（交流/直流）、热、冷、氢、气等 8 类载能体，40+ 种设备模型：光伏/风机/外部电源、制冷与热泵、电解制氢与燃料电池、蓄电/蓄冷/蓄热/储氢、变压器与 MMC、柔性负荷等 |
| **系统约束与自定义 DSL**    | 绿电占比、上网比例、自消纳率、弃电率、保供等合规约束内置为模板；工程规则可用自定义约束 DSL 描述，内核自动编译进模型                                             |
| **工程专项能力**            | 储能保供、机组组合（UC）启停排班、柔性负荷调度（无极/挡位）、全生命周期设备替换、财务后评估（11 张标准财务报表）                                                |
| **结果与报告**              | 多方案独立配置与指标并排比选、能量平衡图（全年 8760 h / 逐月 / 典型日 24 h）、一键生成图文并茂的 Word 项目报告                                                  |

## 模块构成

平台由云空间（项目管理）与三个核心模块构成，一条流水线走完"数据 → 拓扑 → 方案"：

| 模块                                         | 作用                                                                                                            |
| :------------------------------------------- | :-------------------------------------------------------------------------------------------------------------- |
| [云空间](./30-cloud-space/index.md)           | 新建、查看与编辑项目组及项目，管理算例资产                                                                      |
| [数据管理](./40-data-module/index.md)         | 录入并管理**气象数据、设备型号库、负荷曲线、能源价格**（电/冷/热/氢/氨/燃料）——优化的**数据底座** |
| [拓扑建模](./50-topology-module/index.md)     | 在 SimStudio 工作台拖拽元件、连接拓扑，绑定数据，设置元件约束与运行策略                                         |
| [方案优化](./60-optimization-module/index.md) | 配置优化参数并求解，得到设备配置与运行策略，查看结果、比选方案、导出报告                                        |

> **三步环环相扣，不建议跳步**：**数据准备 → 拓扑搭建 → 方案配置 → 启动计算 → 结果查看**。拓扑中的元件要**绑定**数据管理里录入的气象/设备/负荷/电价；优化参数又依赖拓扑中选定的设备与约束；任何一步遗漏，都会在下一步算不出结果。完整操作顺序见[快速入门](./20-quick-start/index.md)

## 应用场景

面向**楼宇级、园区级、区域级**的综合能源系统（含综合电网、综合热力、综合氢能等形态），典型使用阶段：

1. **项目初期设计**：资料有限时，用平台内置的气象、典型设备、负荷与电价数据快速搭建算例，评估投资量级与项目可行性；
2. **可行性方案论证**：在确定的设备池、负荷与价格边界下，对多个设计方案比选论证，形成可研方案；
3. **升级改造与运营计划**：利用详细的设备、负荷与价格历史数据做更精细的设计分析；也可用预测数据评估未来一段时间的运行方式，支撑运营计划制定；
4. **运行优化**：针对确定的拓扑与容量配置优化全年运行方式，评估新能源消纳、运维费用、碳排放等经济性与环保性指标。

**两个重点工程场景**：

- **绿电直连**：把"绿电占比、上网比例、新能源消纳比例"等合规指标直接建模为优化约束，规划结果天然合规，并自动输出年度/月度合规统计与可行性分析报告；
- **AIDC 算电协同**：把人工智能数据中心视作高载能、强波动、可调节的综合能源负荷，将 IT 算力负荷、冷却负荷、储能平抑、柴发备电与算力柔性化统一纳入同一套规划优化框架。

> **能力边界**：平台是**稳态规划**、**线性优化**、**确定性优化**工具——不含电磁暂态仿真与全非线性交流潮流，不做随机/鲁棒优化与电力市场竞价策略，也不涉及施工时序与实时调度控制。更详细的适用/不适用清单见[基本原理 · 功能定位](./60-optimization-module/10-fundamentals/index.md)。

## 工具定位

**计算交给平台，决策留给用户**：作为一款**设计辅助工具**，平台把重复、繁琐、易错的计算交给机器，把**工程判断与责任**留给工程师：

- 求解器返回"最优"，只代表**在您给定的模型与数据下**找到了成本最低的可行方案；模型或数据本身有问题时，它同样会返回一个"最优的错误答案"；
- 数据是否真实、约束与参数是否合理、方案是否值得投资，仍需使用者判断——**"求解成功"不等于"结果正确"**；
- 平台为此提供了完整的方法与工具：结果正确性判定（四级校验）与优化调试技巧，见[方案优化 · 基本原理](./60-optimization-module/10-fundamentals/index.md)与[结果页面 · 优化调试技巧](./60-optimization-module/30-results-tab/index.md)。
